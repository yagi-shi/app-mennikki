## 1. アプリ起動・画面遷移

| No | 試験内容 | 合格条件 | 合否 |
| ---- | ---- | ---- | ---- |
| 1-1 | アプリを起動する | 記録一覧画面がTabBarの「記録」タブで表示される | [✅] |
| 1-2 | TabBarの「お気に入り」タブをタップする | お気に入り一覧画面に切り替わる | [✅] |
| 1-3 | TabBarの「記録」タブをタップする | 記録一覧画面に戻る | [✅] |
| 1-4 | 記録が0件の状態で記録一覧画面を表示する | 空状態のアイコンとメッセージが表示される | [✅] |
| 1-5 | お気に入りが0件の状態でお気に入り一覧画面を表示する | 空状態のアイコン（heart.circle）と「お気に入りがありません」が表示される | [✅] |
