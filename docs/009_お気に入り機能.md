# 009. お気に入り機能

## 概要
記録をお気に入りに登録・解除する機能と、お気に入り一覧を表示する機能を実装する。

## 実装内容

### 1. お気に入り切り替えボタンの実装
- RecordDetailViewControllerのNavigationBarにお気に入りボタン追加
- アイコン: heart.fill（オン時、プライマリカラー）/ heart（オフ時、グレー）
- タップ時: バウンス + 360度回転アニメーション（0.3秒）

### 2. スワイプアクションの実装
- RecordListViewControllerのセルにスワイプアクション追加
- UISwipeActionsConfigurationを使用
- スワイプアクション背景: プライマリカラー
- アイコン: heart.fill（白色）

### 3. お気に入り状態の管理
- Core DataのisFavoriteフィールドを更新
- 変更をNSFetchedResultsControllerに反映

### 4. FavoriteListViewControllerの実装
- RecordListViewControllerと同様の2列グリッドレイアウト
- isFavorite = trueの記録のみを表示
- NSFetchedResultsControllerでフィルタリング

### 5. お気に入り一覧の空状態
- お気に入りが0件の場合のEmpty State表示
- アイコン: heart.circle（80×80pt、薄いグレー）
- メッセージ: 「お気に入りがありません」
- サブメッセージ: 「気に入ったラーメンを記録してみましょう！」

### 6. お気に入りバッジの表示
- RecordCellにお気に入りアイコンを表示
- 右上（写真の上に重なる）、heart.fill（赤、半透明白背景の円形）
