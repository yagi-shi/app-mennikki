# 007. 記録編集機能

## 概要
既存の記録を編集・削除する機能を実装する。

## 実装内容

### 1. 編集機能の実装
- 詳細画面の編集ボタン（pencil）タップ → AddRecordViewControllerをモーダル表示
- `init(recordToEdit:)` で編集モードを起動
- 既存データをフォームに初期値として設定（loadExistingData()）
  - 店舗名、ラーメン種類チップ選択、都道府県、訪問日、費用、評価、コメント、写真

### 2. 編集モード時のUI
- NavigationBarタイトル: 「記録を編集」
- 左ボタン: xmarkアイコン（キャンセル）
- 保存ボタン: 画面下部（新規登録と同様の3Dスタイル）
- フォーム要素は新規登録と完全に共通

### 3. 更新処理
- バリデーション（新規登録と同一ルール）
- CoreDataManager.updateRecord()でCore Data更新
- 写真が変更された場合のみリサイズ処理
- 既存写真が変更されていない場合はrecordToEdit.photoをそのまま使用
- 保存成功: チェックマークアニメーション → モーダルを閉じる

### 4. 編集後の詳細画面更新
- RecordDetailViewControllerのviewWillAppear()でrecordIDから再取得
- infoStack再描画、お気に入りボタン更新

### 5. 削除機能の実装
- 詳細画面のNavigationBar右ボタン（trashアイコン、appPrimary色）
- 閲覧モードで常時表示
- タップ時にUIAlertController（.alert）で確認
  - タイトル: 「記録を削除しますか？」
  - メッセージ: 「この操作は取り消せません」
  - ボタン: 「キャンセル」（cancel）「削除」（destructive）
- 削除実行: CoreDataManager.deleteRecord() → popViewController
- 削除失敗: エラーアラート表示
