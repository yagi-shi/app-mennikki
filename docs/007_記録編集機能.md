# 007. 記録編集機能

## 概要
既存の記録を編集・削除する機能を実装する。

## 実装内容

### 1. 編集モードの実装
- RecordDetailViewControllerに編集モードを追加
- 編集ボタンタップで編集モードに切り替え
- 編集モードでは新規登録と同様のUIで既存データを編集可能

### 2. 編集モード時のNavigationBar
- 左: 「キャンセル」ボタン（グレー）
- 右: 「保存」ボタン（プライマリカラー、Bold）

### 3. フォーム要素の切り替え
- 閲覧モード: 静的な表示
- 編集モード: 入力可能なフォーム
- 既存データの初期値設定

### 4. 更新処理
- バリデーション
- Core Dataの更新
- 保存成功時のアニメーション

### 5. 削除機能の実装
- 画面下部に「削除」ボタン配置
- タップ時にUIAlertControllerで確認
  - タイトル: 「記録を削除しますか？」
  - メッセージ: 「この操作は取り消せません」
  - ボタン: 「キャンセル」「削除」（destructive）
- 削除実行時: フェードアウト → 前の画面に戻る
