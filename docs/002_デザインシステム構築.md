# 002. デザインシステム構築

## 概要
ポップなデザインシステムを構築し、アプリ全体で統一したスタイルを使用できるようにする。

## 実装内容

### 1. カラーパレット定義（UIColor+App.swift）
- UIColor extensionで定義
  - appPrimary: #FF4B4B（red）
  - appSecondary: #1CB0F6（blue）
  - appSuccess: #58CC02（green）
  - appBackground: #F7F7F7
  - appCardBackground: #FFFFFF
  - appText: #3C3C3C
  - appSecondaryText: #AFAFAF
  - appBorder: #E5E5E5
  - appFieldBorder: rgba(149, 165, 166, 0.2)
  - appCardBorder: #EBEBEB
- ラーメン種類別カラー（colorForRamenType / tagColorForRamenType）
  - 11種類それぞれに固有の鮮やかなカラーを定義
  - タグ用は15%不透明度版

### 2. タイポグラフィ定義（UIFont+App.swift）
- UIFont extensionで定義
- `rounded(ofSize:weight:)` メソッドで丸みのあるシステムフォントを生成
- UIFontMetricsによるDynamic Typeスケーリング
  - appLargeTitle: 28pt heavy
  - appNavigationTitle: 20pt bold
  - appSectionHeader: 18pt bold
  - appStoreName: 17pt bold
  - appRamenType: 15pt semibold
  - appBody: 15pt medium
  - appCaption: 13pt medium
  - appDetailTitle: 24pt heavy
  - appButton: 16pt bold
  - appTag: 12pt bold

### 3. UIコンポーネントスタイル定義（UIView+App.swift）
- `applyCardShadow()` — カードシャドウ
- `applyGradient()` — グラデーションレイヤー（既存レイヤー自動除去）
- `bounceAnimation()` — スプリングバウンス効果
- `fadeInWithSlide()` — フェードイン+上方向スライドアニメーション

### 4. NavigationBar / TabBarスタイル
- UINavigationBar+App.swift: `applyAppStyle()` — 白背景、roundedフォント、appBorderシャドウ
- UITabBar+App.swift: `applyAppStyle()` — 白背景、roundedフォント、appBorderトップボーダー
