## 1. Core Data Entity

### Record（記録）

ラーメンの食事記録を保存するエンティティ。

| フィールド | 型 | 必須 | デフォルト値 | 備考 |
|---|---|---|---|---|
| id | UUID | ✓ | 自動生成 | レコードの一意識別子 |
| storeName | String | ✓ | - | 店舗名（自由入力、最大100文字） |
| ramenType | String | ✓ | - | ラーメンの種類（Enumから文字列で保存） |
| visitDate | Date | ✓ | - | 訪問日 |
| cost | Int16 | - | 0 | 費用（円）、0は未入力扱い、最大9999 |
| rating | Int16 | ✓ | 0 | 星評価（1〜5）、新規登録時は1以上必須 |
| comment | String | - | - | コメント（自由入力、最大500文字） |
| photo | Binary Data | - | - | ラーメンの写真データ |
| isFavorite | Bool | ✓ | false | お気に入りフラグ |
| prefecture | String | - | - | 都道府県（Prefecture Enumから文字列で保存） |
| createdAt | Date | ✓ | 自動設定 | 作成日時 |

## 2. RamenType Enum

ラーメンの種類を定義するEnum。String rawValueで管理し、Core DataにはrawValueを保存する。

```swift
enum RamenType: String, CaseIterable {
    case shoyu    = "醤油"
    case shio     = "塩"
    case miso     = "味噌"
    case tonkotsu = "豚骨"
    case niboshi  = "煮干し"
    case paitan   = "白湯"
    case tsukemen = "つけ麺"
    case mazemen  = "汁なし"
    case jiro     = "二郎系"
    case iekei    = "家系"
    case other    = "その他"
}
```

### 使用方法

```swift
// Core Dataへの保存
record.ramenType = RamenType.shoyu.rawValue

// Core Dataからの読み込み
if let ramenType = RamenType(rawValue: record.ramenType) {
    // ramenTypeを使用
}
```

## 3. Prefecture Enum

47都道府県を定義するEnum。String rawValueで管理し、Core DataにはrawValueを保存する。

```swift
enum Prefecture: String, CaseIterable {
    case hokkaido = "北海道"
    case aomori   = "青森県"
    // ... 全47都道府県
    case okinawa  = "沖縄県"
}
```

## 4. データの検証ルール

### 必須項目
- 店舗名（storeName）: 空文字列不可、100文字以内
- ラーメンの種類（ramenType）: RamenType Enumのいずれか
- 訪問日（visitDate）: 有効な日付（未来日は不可）
- 評価（rating）: 1〜5の範囲（新規登録・編集時は必須）

### オプション項目
- 費用（cost）: 0の場合は未入力扱い、最大9999
- コメント（comment）: 任意の文字列、500文字以内
- 写真（photo）: 任意のバイナリデータ
- 都道府県（prefecture）: Prefecture Enumのいずれか

---

## 5. 画像データの管理

### リサイズ
- 保存前に適切なサイズにリサイズ（最大長辺800px）
- アスペクト比を維持
- JPEG圧縮品質: 0.75
- UIGraphicsImageRendererを使用

### キャッシュ
- メモリキャッシュ: NSCache（RecordCellで静的共有、自動解放）
- ダウンサンプリング: CGImageSourceCreateThumbnailAtIndex（最大300px）
- ディスクキャッシュ: Core Dataに保存

## 6. Core Data設定

### NSPersistentContainer設定

```swift
lazy var persistentContainer: NSPersistentContainer = {
    let container = NSPersistentContainer(name: "mennikki")
    // ファイル保護レベル設定
    let description = container.persistentStoreDescriptions.first
    description?.setOption(FileProtectionType.complete as NSObject,
                          forKey: NSPersistentStoreFileProtectionKey)
    container.loadPersistentStores { description, error in
        if let error = error {
            // エラーログ出力（fatalErrorは使用しない）
        }
    }
    return container
}()
```

### Context管理
- **Main Context**: UI更新用（viewContext）
- **Background Context**: データ保存・更新用（newBackgroundContext()）

// 訪問日の新しい順でソート

## 8. データマイグレーション

### 方針
- Lightweight Migration を優先
- 互換性のない変更の場合はManual Migrationを実装

### 注意事項
- データモデル変更時は新しいバージョンを作成
- マイグレーションポリシーを定義
- ユーザーデータの保護を最優先
