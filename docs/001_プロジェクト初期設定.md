# 001. プロジェクト初期設定

## 概要
プロジェクトの初期設定とCore Dataの構築を行う。

## 実装内容

### 1. Storyboard削除とコードベース設定
- Main.storyboardの削除
- Info.plistの設定変更（Main storyboardの参照削除）
- SceneDelegateでUIWindowの初期化設定

### 2. Core Dataスタックの構築
- Core Data Modelの作成（mennikki.xcdatamodeld）
- RecordエンティティのAttributeの定義
  - id: UUID
  - storeName: String
  - ramenType: String
  - visitDate: Date
  - cost: Int16
  - rating: Int16
  - comment: String
  - photo: Binary Data
  - isFavorite: Boolean
  - prefecture: String
  - createdAt: Date

### 3. Core Dataマネージャーの作成
- CoreDataManager シングルトンクラス
- NSPersistentContainerの設定（ファイル保護レベル: FileProtectionType.complete）
- isStoreLoadedフラグによるストア状態管理
- os.Loggerによるログ出力
- CRUD操作メソッド
  - createRecord() → Record?
  - updateRecord() → Bool
  - deleteRecord() → Bool
  - toggleFavorite() → Bool
  - fetchAllRecords() → [Record]
  - fetchFavoriteRecords() → [Record]
  - searchRecords() → [Record]
  - fetchDistinctPrefectures() → [String]
- saveIfNeeded()（アプリバックグラウンド時呼び出し）

### 4. RamenType Enumの定義
- 11種類のラーメンタイプの定義（醤油、塩、味噌、豚骨、煮干し、白湯、つけ麺、汁なし、二郎系、家系、その他）
- String rawValueでの管理
- CaseIterable準拠

### 5. Prefecture Enumの定義
- 47都道府県の定義
- String rawValueでの管理
- CaseIterable準拠
