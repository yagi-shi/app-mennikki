## 概要
プロジェクトの初期設定とCore Dataの構築を行う。

## 実装内容

### 1. Storyboard削除とコードベース設定
- Main.storyboardの削除
- Info.plistの設定変更（Main storyboardの参照削除）
- SceneDelegateでUIWindowの初期化設定

### 2. Core Dataスタックの構築
- Core Data Modelの作成（mennikki.xcdatamodeld）
- RecordエンティティのAttributeの定義

  - storeName: String
  - ramenType: String
  - visitDate: Date
  - cost: Int16
  - rating: Int16
  - comment: String
  - photo: Binary Data
  - isFavorite: Boolean
  - createdAt: Date

### 3. Core Dataマネージャーの作成
- NSPersistentContainerの設定
- CRUD操作の基本メソッド実装
- エラーハンドリング

### 4. RamenType Enumの定義
- 10種類のラーメンタイプの定義
- String rawValueでの管理
