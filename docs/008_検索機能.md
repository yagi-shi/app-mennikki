# 008. 検索機能

## 概要
店名、ラーメンの種類、都道府県で記録を検索・フィルタリングする機能を実装する。

## 実装内容

### 1. UISearchControllerの追加
- RecordListViewControllerにUISearchControllerを配置
- navigationItem.searchControllerに設定
- hidesSearchBarWhenScrolling: true

### 2. UISearchBarのカスタマイズ
- プレースホルダー: 「店名で検索」
- キャンセルボタン: appPrimary色
- 検索フィールド背景: 白

### 3. 店名検索の実装
- 部分一致検索（大文字小文字を区別しない）
- NSPredicate: `storeName CONTAINS[cd] %@`
- UISearchResultsUpdating準拠
- デバウンス: 0.3秒遅延（Timer）

### 4. ラーメン種類フィルターの実装
- NavigationBar右ボタン1: line.3.horizontal.decrease.circle
- タップでUIAlertController（actionSheet）を表示
- RamenType.allCases全11種類を表示
- チェックマーク（✓）で選択状態を表示
- 複数選択対応（selectedRamenTypes配列で管理）
- 選択中は「フィルターをクリア」アクション（destructive）を表示
- iPad対応: popoverPresentationController設定

### 5. 都道府県フィルターの実装
- NavigationBar右ボタン2: mappin.circle
- タップでUIAlertController（actionSheet）を表示
- 記録に存在する都道府県のみ動的に表示（fetchDistinctPrefectures）
- Prefecture.allCasesの順序でソート
- 該当なしの場合はアラートメッセージ表示
- 単一選択（selectedPrefecture）
- 選択中は「フィルターをクリア」アクション（destructive）を表示

### 6. 複合フィルターロジック
- 店名検索、種類フィルター、都道府県フィルターをAND条件で組合せ
- NSCompoundPredicate(andPredicateWithSubpredicates:) を使用
- fetchPredicate()をオーバーライドして実装

### 7. 検索結果の表示
- NSFetchedResultsControllerのpredicateを更新
- performFetch() + collectionView.reloadData()
- animatedCellsをリセットしてスタガーアニメーション再実行
- 空状態表示の更新
