# 008. 検索機能

## 概要
店名とラーメンの種類で記録を検索・フィルタリングする機能を実装する。

## 実装内容

### 1. UISearchControllerの追加
- RecordListViewControllerにUISearchControllerを配置
- navigationItem.searchControllerに設定

### 2. UISearchBarのカスタマイズ
- プレースホルダー: 「店名やラーメンの種類で検索」
- 検索アイコン: magnifyingglass（セカンダリカラー）
- キャンセルボタン: プライマリカラー
- 背景: 明るいグレー

### 3. 店名検索の実装
- 部分一致検索（大文字小文字を区別しない）
- NSPredicateを使用
- リアルタイム検索（updateSearchResults(for:)）

### 4. ラーメン種類フィルターの実装
- NavigationBarに「フィルター」ボタン追加（line.3.horizontal.decrease.circle）
- タップでUIAlertControllerまたはカスタムビューで複数選択
- 選択された種類をタグ形式で検索バー下に表示

### 5. 検索結果の表示
- UICollectionViewを更新
- 検索結果が0件の場合: Empty State表示
  - アイコン: magnifyingglass.circle（80×80pt）
  - メッセージ: 「検索結果が見つかりませんでした」

### 6. NSFetchedResultsControllerの更新
- 検索条件に応じてpredicateを更新
