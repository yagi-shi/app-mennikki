# 005. 新規記録画面

## 概要
ラーメンの記録を新規作成するフォーム画面を実装する。

## 実装内容

### 1. AddRecordViewControllerの作成
- UIScrollView内にフォームを配置
- 背景色: 明るいグレー（#F7F7F7）

### 2. フォーム要素の実装
- **店名**: UITextField（高さ48pt、角丸12pt、ボーダー2pt）
- **ラーメンの種類**: UIButton（タグ形式、イエロー背景）
  - タップでUIAlertController（actionSheet）で選択
- **訪問日**: UIDatePicker（inline style）
  - デフォルト値: 本日
  - 白色カード背景、角丸12pt
- **費用**: UITextField（数値パッド）
- **評価**: カスタム星評価ビュー（5つ星、タップでバウンス）
- **コメント**: UITextView（角丸12pt、最小高さ100pt）
- **写真**: UIButton + UIImageView
  - 未選択時: 破線ボーダー、カメラアイコン
  - 選択後: 写真表示（200×200pt、角丸12pt）

### 3. NavigationBarの設定
- タイトル: "新規記録"
- 右ボタン: "保存"（プライマリカラー、Bold）
- 左ボタン: "キャンセル"（グレー）

### 4. 写真選択機能
- PHPickerViewControllerの表示
- 選択した画像の表示

### 5. バリデーションと保存処理
- 店名、ラーメンの種類、訪問日は必須
- Core Dataへの保存
- 保存成功時のアニメーション（チェックマーク + フラッシュ）

### 6. RecordListViewControllerからの遷移
- NavigationBarに「+」ボタン追加
- モーダル表示
