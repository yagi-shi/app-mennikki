# 010. アクセシビリティ対応

## 概要
VoiceOverなどのアクセシビリティ機能に対応する。

## 実装内容

### 1. アクセシビリティラベルの設定
- **RecordCell**: "店名、ラーメンの種類"
- **FABボタン**: "新しい記録を追加"
- **お気に入りボタン**: "お気に入り登録" / "お気に入り解除"（状態により変化）
- **削除ボタン**: "記録を削除"
- **StarRatingView**: 各星ボタンに "X星"
- **情報行**: "タイトル、値"（例: "訪問日、2026年2月1日（土）"）
- **フォーム要素**: "店舗名"、"費用"、"コメント"、"写真を選択"、"保存"
- **ラーメン種類チップ**: 各種類名をaccessibilityLabel

### 2. アクセシビリティヒントの設定
- **RecordCell**: "ダブルタップして詳細を表示"
- FABボタン: buttonトレイトにより自動

### 3. アクセシビリティトレイトの設定
- **FABボタン**: .button
- **StarRatingView**: 選択時 .selected トレイト
- **店名ラベル**（詳細画面）: .header
- **ラーメン種類チップ**: 選択時 .selected トレイト

### 4. Dynamic Typeへの対応
- UIFont+App.swiftで全フォントにUIFontMetricsスケーリング適用
- `rounded(ofSize:weight:)` → UIFontMetrics(forTextStyle:).scaledFont()
- 対応テキストスタイル: .largeTitle, .title2, .title3, .headline, .subheadline, .body, .caption1, .caption2, .callout

### 5. RecordDetailViewControllerのアクセシビリティ
- ViewController自体: isAccessibilityElement = false（子要素を個別にフォーカス）
- 店名: .headerトレイト
- 情報行: コンテナ単位でisAccessibilityElement = true
