# 006. 記録詳細画面

## 概要
記録の詳細情報を表示する画面を実装する。

## 実装内容

### 1. RecordDetailViewControllerの作成
- UIScrollView > contentView内に詳細情報を配置
- 背景色: 白
- recordID（NSManagedObjectID）で記録を管理

### 2. ヘッダーエリア（220pt高さ）
- 写真がある場合: scaleAspectFill表示（バックグラウンドデコード）
- 写真がない場合: ラーメン種類カラー背景 + fork.knifeプレースホルダー（60pt thin、白60%透過）

### 3. 情報エリア（白背景）
- **店名**: appDetailTitle（24pt heavy）、2行まで
- **ラーメン種類タグ**: 種類カラー背景、白テキスト、角丸11pt、パディング上下4pt/左右10pt
- **星評価**: StarRatingView（読み取り専用、isUserInteractionEnabled=false）
  - コンテナ高さ44pt、rating=0で非表示
- **情報行スタック**（UIStackView、条件付き表示）
  - 都道府県: mappin.circleアイコン（appPrimary）
  - 訪問日: calendarアイコン（appSecondary）、"yyyy年M月d日（E）"形式
  - 費用: yensign.circleアイコン（appSuccess）、"¥{金額}"
  - 各行: 高さ60pt、アイコン22x22pt + タイトル（appCaption）+ 値（15pt bold）
  - 行間に1pt区切り線（appBorder）
- **コメント**: appBackground色カード、角丸16pt、パディング16pt
  - 未入力時はカードごと非表示

### 4. NavigationBarの設定
- タイトル: なし（空文字列）
- largeTitleDisplayMode: .never
- 右ボタン（右から順に）:
  1. 編集: pencilアイコン（appSecondaryText色）
  2. お気に入り: UIButton customView、heart/heart.fill（18pt）
  3. 削除: trashアイコン（appPrimary色）

### 5. お気に入りボタン
- UIButton（customView）でNavigationBarに配置
- オン: heart.fill（appPrimary色）/ オフ: heart（appSecondaryText色）
- タップ: CoreDataManager.toggleFavorite() → バウンスアニメーション（1.4倍、0.12秒）
- アクセシビリティラベル: "お気に入り登録" / "お気に入り解除"

### 6. 画面更新
- viewWillAppear()でrecordIDから最新データを再取得
- infoStack再描画、お気に入りボタン更新
- 記録が削除されていた場合はpopViewController

### 7. RecordListViewController / FavoriteListViewControllerからの遷移
- セルタップで詳細画面へプッシュ遷移
