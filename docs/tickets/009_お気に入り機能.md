# 009. お気に入り機能

## 概要
記録をお気に入りに登録・解除する機能と、お気に入り一覧を表示する機能を実装する。

## 実装内容

### 1. お気に入り切り替えボタンの実装
- RecordDetailViewControllerのNavigationBarにUIButton（customView）として配置
- アイコン（18pt regular）:
  - オン時: heart.fill（appPrimary色）
  - オフ時: heart（appSecondaryText色）
- タップ時:
  - CoreDataManager.toggleFavorite()で状態切替
  - ボタン画像・色を即時更新
  - バウンスアニメーション（1.4倍スケール、0.12秒）
- アクセシビリティラベル: "お気に入り登録" / "お気に入り解除"

### 2. お気に入り状態の管理
- Core DataのisFavoriteフィールドを更新
- 変更はNSFetchedResultsControllerに自動反映

### 3. FavoriteListViewControllerの実装
- BaseRecordListViewControllerを継承（共通基底クラス）
- fetchPredicate(): `isFavorite == true`
- タイトル: "お気に入り"（largeTitleDisplayMode: .never）
- viewWillAppear()でNSFetchedResultsControllerを再フェッチ
  - animatedCellsリセット + リロード + 空状態更新

### 4. お気に入り一覧の空状態
- アイコン: heart.circle（80pt、appSecondaryText色）
- メッセージ: 「お気に入りがありません」
- サブメッセージ: 「気に入ったラーメンを記録してみましょう！」

### 5. お気に入りバッジ（RecordCell）
- セルの右上に配置（8ptマージン）
- appPrimary背景の円形（24x24pt、cornerRadius 12pt）
- 白heart.fillアイコン（10pt bold）
- isFavorite = trueの場合のみ表示
