# デザインガイドライン

## コンセプト

Duolingo を参考にした、明るく楽しいUI。

- 白いカードに鮮やかなアクセントカラー
- 角丸・ハードシャドウで「押し込める」立体感
- 太めフォントで読みやすいテキスト階層
- タップ時にカードが沈み込むアニメーション（Duolingo の 3D ボタン効果）
