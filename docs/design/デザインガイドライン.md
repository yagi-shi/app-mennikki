**作成日:** 2026年2月1日
**更新日:** 2026年2月7日

## 1. デザインコンセプト

Duolingoのような明るく親しみやすい、カラフルで丸みのあるデザイン。ユーザーが楽しくラーメン記録を続けられるよう、ポジティブで視覚的に魅力的なUIを目指す。

**キーワード**: 明るい、親しみやすい、カラフル、丸み、楽しい

## 4. UI要素のスタイル

### 4.1 カード/セルデザイン

- **角丸**: `cornerRadius = 12pt`
- **シャドウ**:
  - `shadowOpacity = 0.1`
  - `shadowRadius = 8`
  - `shadowOffset = (0, 2)`
  - `shadowColor = UIColor.black.cgColor`
- **マージン**: 左右16pt、上下8pt
- **内部パディング**:
  - CollectionViewセル: 8pt
  - その他のカード: 16pt
- **背景**: 白色

### 4.2 CollectionViewカードレイアウト（2列グリッド）

- **列数**: 2列
- **セル間隔**: 水平12pt、垂直12pt（minimumInteritemSpacing、minimumLineSpacing）
- **セクションインセット**: 上下左右16pt
- **セルサイズ計算**: `(画面幅 - 左右マージン32pt - 列間隔12pt) / 2`
- **アスペクト比**: 幅:高さ = 1:1.3（縦長カード）
- **写真エリア**: セル上部、高さ120pt、角丸12pt（上部のみ）
- **テキストエリア**: 写真の下、パディング8pt
- **お気に入りバッジ**: 右上、写真の上に重なる（absolute positioning）

### 4.3 ボタンデザイン

#### プライマリボタン
- **背景**: プライマリカラー（グラデーション推奨）
- **テキスト**: 白色、Bold
- **角丸**: 24pt（完全な丸み）
- **高さ**: 50pt
- **タップ時**: わずかにスケールダウン（0.95倍）のアニメーション

#### セカンダリボタン
- **背景**: 透明
- **ボーダー**: 2pt、セカンダリカラー
- **テキスト**: セカンダリカラー、Semibold
- **角丸**: 24pt

#### アイコンボタン
- **サイズ**: 44×44pt（タップエリア確保）
- **アイコンサイズ**: 24×24pt
- **背景**: 円形、半透明

### 4.4 テキストフィールド

- **角丸**: 12pt
- **ボーダー**: 2pt、薄いグレー
- **フォーカス時**: ボーダーカラーをプライマリカラーに変更、アニメーション
- **高さ**: 48pt
- **パディング**: 左右16pt

### 4.5 星評価

- **アイコン**: SF Symbols の `star.fill`
- **サイズ**: 28×28pt（入力時）、32×32pt（詳細表示時）
- **色**:
  - 選択時: セカンダリカラー
  - 未選択時: 薄いグレー
- **間隔**: 8pt
- **アニメーション**: タップ時にバウンス（スケール1.0 → 1.2 → 1.0）

### 4.6 タグ（ラーメン種類）

- **背景**: タグ背景カラー（#FFE66D）
- **テキスト**: ダークグレー、Medium
- **角丸**: 16pt
- **パディング**: 上下8pt、左右12pt
- **フォントサイズ**: 13pt

### 4.7 写真サムネイル

- **サイズ**:
  - 一覧: 60×60pt
  - 詳細: 200×200pt
  - セル内: 幅いっぱい、高さ120pt
- **角丸**: 12pt（セル内は上部のみ）
- **アスペクト比**: 1:1（正方形）
- **プレースホルダー**: 薄いグレー背景 + カメラアイコン

## 5. アニメーション

| アクション | アニメーション | duration | イージング |
|---|---|---|---|
| セル選択 | スケールダウン（0.97倍） | 0.1秒 | easeInOut |
| ボタンタップ | スケールダウン（0.95倍）+ わずかな影変化 | 0.15秒 | easeInOut |
| お気に入り切り替え | バウンス + 回転（360度） | 0.3秒 | easeInOut |
| 画面遷移 | カスタムトランジション（スライド+フェード） | 0.3秒 | easeInOut |
| 削除確認 | シェイク + アラート表示 | 0.2秒 | easeInOut |
| 保存成功 | チェックマークアニメーション + 背景フラッシュ | 0.5秒 | easeInOut |

### 実装例

```swift
// セル選択アニメーション
UIView.animate(withDuration: 0.1, animations: {
    cell.transform = CGAffineTransform(scaleX: 0.97, y: 0.97)
}) { _ in
    UIView.animate(withDuration: 0.1) {
        cell.transform = .identity
    }
}

// お気に入りボタンアニメーション
UIView.animate(withDuration: 0.3, animations: {
    button.transform = CGAffineTransform(rotationAngle: .pi * 2).scaledBy(x: 1.2, y: 1.2)
}) { _ in
    UIView.animate(withDuration: 0.2) {
        button.transform = .identity
    }
}
```

## 7. 空状態（Empty State）

### 記録0件の場合

- **イラスト**: `bowl.fill`、サイズ80×80pt、薄いグレー
- **メッセージ**: 「まだラーメンの記録がありません」、18pt、Semibold
- **サブメッセージ**: 「＋ボタンから最初の記録を追加しましょう！」、15pt、Regular、グレー
- **配置**: 画面中央、縦方向に整列
- **アニメーション**: ふわっとフェードイン（0.3秒）

### 検索結果0件の場合

- **イラスト**: `magnifyingglass.circle`、サイズ80×80pt、薄いグレー
- **メッセージ**: 「検索結果が見つかりませんでした」、18pt、Semibold

### お気に入り0件の場合

- **イラスト**: `heart.circle`、サイズ80×80pt、薄いグレー
- **メッセージ**: 「お気に入りがありません」、18pt、Semibold
- **サブメッセージ**: 「気に入ったラーメンを記録してみましょう！」、15pt、Regular、グレー

## 8. TabBar・NavigationBarのカスタマイズ

### TabBar（Duolingo風）

- **背景**: 白色
- **上部シャドウ**: shadowOpacity = 0.1、shadowRadius = 4
- **選択時のtintColor**: プライマリカラー
- **未選択時のtintColor**: 薄いグレー
- **タブ項目**:
  1. 記録一覧: アイコン = `fork.knife`、タイトル = "記録"
  2. お気に入り: アイコン = `heart.fill`、タイトル = "お気に入り"

### NavigationBar（Duolingo風）

- **背景**: 白色
- **タイトル**: 20pt、Bold、ダークグレー
- **tintColor**: プライマリカラー（ボタン類）
- **シャドウ**: 薄いシャドウで境界を明確に（shadowOpacity = 0.05）

## 9. レイアウト原則

### スペーシング

- **セクション間**: 20pt
- **要素間**: 16pt
- **小要素間**: 8pt
- **マージン**: 左右16pt

### グリッドシステム

- **基本単位**: 8pt
- 全てのサイズとスペーシングは8の倍数を推奨

---

## 10. アクセシビリティ

### 色のコントラスト

- テキストと背景のコントラスト比: 最低4.5:1（WCAG AA基準）
- 重要な情報は色だけでなく、アイコンやテキストでも伝える

### タップターゲット

- 最小タップエリア: 44×44pt（Apple Human Interface Guidelines）
- ボタンとタップ可能な要素は十分なスペースを確保

### Dynamic Type

- システムフォントサイズの変更に対応
- UIFontMetricsを使用したフォントスケーリング
