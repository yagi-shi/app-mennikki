## 1. 記録の新規登録

### 概要
ラーメンの食事記録を新規作成する機能。

### 画面遷移
- ホーム画面（記録一覧）のNavigationBarの「+」ボタンをタップ
- 新規記録画面をモーダル表示

### UI要素

#### NavigationBar
- タイトル: "新規記録"
- 左ボタン: "キャンセル"（グレー）→ モーダルを閉じる
- 右ボタン: "保存"（プライマリカラー、Bold）→ 保存処理実行

#### フォーム要素（UIScrollView内）

1. **店名**
   - UITextField
   - プレースホルダー: 「店名を入力」
   - 高さ: 48pt、角丸12pt、ボーダー2pt
   - 必須項目

2. **ラーメンの種類**
   - UIButton（カスタムデザイン）
   - 初期表示: 「ラーメンの種類を選択」（グレー）
   - 選択後: タグ形式、イエロー背景
   - タップでUIAlertController（actionSheet）を表示
   - 必須項目

3. **訪問日**
   - UIDatePicker（inline style、iOS 14+）
   - デフォルト値: 本日
   - 白色カード背景、角丸12pt、軽いシャドウ
   - 必須項目

4. **費用**
   - UITextField
   - プレースホルダー: 「費用（円）」
   - キーボードタイプ: 数値パッド
   - 高さ: 48pt
   - オプション項目（0の場合は未入力扱い）

5. **評価**
   - カスタムビュー（5つのUIButton）
   - 星アイコン（star.fill）
   - 色: セカンダリカラー（選択時）、薄いグレー（未選択時）
   - タップでバウンスアニメーション
   - オプション項目（0は未評価）

6. **コメント**
   - UITextView
   - プレースホルダー: 「コメントを入力（オプション）」
   - 角丸12pt、ボーダー2pt
   - 最小高さ: 100pt
   - オプション項目

7. **写真**
   - UIButton + UIImageView
   - 未選択時: 破線ボーダー、camera.fillアイコン、「写真を追加」テキスト
   - 選択後: 写真表示、200×200pt、角丸12pt
   - タップでPHPickerViewController（フォトライブラリ）を表示
   - オプション項目

### レイアウト
- 各フィールド間の間隔: 16pt
- 背景色: 明るいグレー（#F7F7F7）
- 左右マージン: 16pt

### バリデーション
- **店名**: 空文字列不可
- **ラーメンの種類**: 選択必須
- **訪問日**: 有効な日付
- **費用**: 負の値不可
- **評価**: 0〜5の範囲

### 保存処理
1. バリデーションチェック
2. 写真があればリサイズ（最大幅1024px、JPEG品質0.8）
3. Core Dataに保存
4. 保存成功時:
   - チェックマークアニメーション表示
   - 背景フラッシュ
   - 0.5秒後にモーダルを閉じる
5. エラー時: UIAlertControllerでエラーメッセージ表示

### 注意事項
- お気に入りはデフォルトでfalse
- createdAtは自動設定
- idは自動生成（UUID）

## 2. 記録の閲覧

### 概要
記録一覧を2列グリッドレイアウトで表示する機能。

### 画面構成
- UICollectionView（2列グリッド）
- 訪問日の新しい順でソート
- UISearchController配置

### UICollectionViewレイアウト
- レイアウト: UICollectionViewFlowLayout
- 列数: 2列
- セル間隔: 水平12pt、垂直12pt
- セクションインセット: 上下左右16pt
- セルサイズ: `(画面幅 - 左右マージン32pt - 列間隔12pt) / 2`
- アスペクト比: 幅:高さ = 1:1.3（縦長）

### カスタムセル（RecordCell）

表示要素:
1. **写真** - 上部、セル幅いっぱい、高さ120pt、角丸12pt（上部のみ）
   - 写真がない場合: グレー背景 + fork.knifeアイコン（中央配置）
2. **店名** - 15pt、Semibold、ダークグレー、2行まで表示（省略記号）
3. **ラーメンの種類** - タグ形式、イエロー背景、角丸8pt、12pt
4. **訪問日** - 12pt、Regular、グレー、フォーマット: "yyyy/MM/dd"
5. **お気に入りバッジ** - 右上（写真の上に重なる）、heart.fill（赤、半透明白背景の円形）、お気に入りのみ表示

レイアウト:
- 背景: 白色、角丸12pt、軽いシャドウ
- 内部パディング: 8pt

### インタラクション
- セルタップ: 詳細画面へプッシュ遷移
- タップ時アニメーション: 0.95倍スケールダウン（0.1秒）

### 空状態
記録が0件の場合:
- アイコン: bowl.fill（80×80pt、薄いグレー）
- メッセージ: 「まだラーメンの記録がありません」
- サブメッセージ: 「＋ボタンから最初の記録を追加しましょう！」
- ふわっとフェードイン（0.3秒）

### NavigationBar
- タイトル: "記録"
- 右ボタン1: "+"ボタン（plus.circle.fill、プライマリカラー）→ 新規記録画面へ
- 右ボタン2: フィルターボタン（line.3.horizontal.decrease.circle）→ ラーメン種類フィルター

## 3. 記録詳細の表示

### 概要
記録の詳細情報を表示する画面。

### 画面構成
- UIScrollView内に詳細情報を配置
- 背景色: 明るいグレー（#F7F7F7）

### 表示要素

1. **写真** - 上部、200×200pt、角丸12pt
   - 写真がない場合: プレースホルダー（グレー背景 + fork.knifeアイコン）

2. **店名** - 24pt、Bold、ダークグレー

3. **ラーメンの種類** - タグ形式、イエロー背景、中央寄せ、角丸16pt

4. **訪問日** - カレンダーアイコン（calendar） + 日付テキスト（フォーマット: "yyyy年MM月dd日"）

5. **費用** - 円マーク + 金額
   - 未入力時: "費用: -"

6. **評価** - 星表示（読み取り専用）
   - サイズ: 32×32pt
   - 色: セカンダリカラー（選択時）、薄いグレー（未選択時）
   - 未評価時: 全て薄いグレー

7. **コメント** - 白色カード内、角丸12pt、テキスト表示
   - 未入力時: セクションごと非表示

### レイアウト
- 各セクション間の間隔: 20pt
- 左右マージン: 16pt

### NavigationBar
- タイトル: 店名
- 右ボタン1: お気に入りボタン（heart.fill/heart）
- 右ボタン2: 編集ボタン（pencil.circle.fill、セカンダリカラー）

## 4. 記録の編集・削除

### 編集機能

#### 編集モードへの移行
- 詳細画面の編集ボタンをタップ
- 編集モードに切り替え（閲覧モード → 編集モード）

#### 編集モード時のUI
- 新規登録と同様のフォーム表示
- 既存データが初期値として設定
- NavigationBar:
  - 左: 「キャンセル」ボタン（グレー）
  - 右: 「保存」ボタン（プライマリカラー、Bold）

#### 保存処理
1. バリデーションチェック
2. 写真が変更されていればリサイズ
3. Core Dataを更新
4. 保存成功時:
   - チェックマークアニメーション
   - 背景フラッシュ
   - 閲覧モードに戻る
5. エラー時: UIAlertControllerでエラーメッセージ

#### キャンセル処理
- 変更を破棄
- 閲覧モードに戻る

### 削除機能

#### 削除ボタンの配置
- 編集モード時、画面下部に配置
- スタイル:
  - 幅: 画面幅いっぱい
  - 高さ: 50pt
  - 背景: 透明
  - テキスト: プライマリカラー（赤系）、「この記録を削除」

#### 削除確認
- タップ時にUIAlertControllerで確認
  - タイトル: 「記録を削除しますか？」
  - メッセージ: 「この操作は取り消せません」
  - ボタン:
    - 「キャンセル」（デフォルトスタイル）
    - 「削除」（destructiveスタイル）

#### 削除処理
1. Core Dataから削除
2. フェードアウトアニメーション
3. 前の画面（記録一覧）に戻る

## 5. 検索機能

### 概要
店名とラーメンの種類で記録を検索・フィルタリングする機能。

### UISearchController

#### 配置
- 記録一覧画面のnavigationItem.searchControllerに設定

#### カスタマイズ
- プレースホルダー: 「店名やラーメンの種類で検索」
- 検索アイコン: magnifyingglass（セカンダリカラー）
- キャンセルボタン: プライマリカラー
- 背景: 明るいグレー

### 店名検索

#### 検索ロジック
- 部分一致（大文字小文字を区別しない）
- NSPredicate: `storeName CONTAINS[cd] %@`
- リアルタイム検索（updateSearchResults(for:)）

### ラーメン種類フィルター

#### フィルターボタン
- NavigationBarに「フィルター」ボタン配置（line.3.horizontal.decrease.circle）
- タップでUIAlertController（actionSheet）を表示

#### 複数選択
- RamenType Enumの全種類を表示
- チェックボックス形式で複数選択可能
- 選択された種類をタグ形式で検索バー下に表示

#### フィルターロジック
- NSPredicate: `ramenType IN %@`
- 店名検索とフィルターは同時に適用可能（AND条件）

### 検索結果の表示
- UICollectionViewをリアルタイム更新
- NSFetchedResultsControllerのpredicateを更新

### 検索結果0件の場合
- 空状態を表示
  - アイコン: magnifyingglass.circle（80×80pt、薄いグレー）
  - メッセージ: 「検索結果が見つかりませんでした」

## 6. お気に入り機能

### 概要
記録をお気に入りに登録・解除する機能と、お気に入り一覧を表示する機能。

### お気に入りの切り替え

#### 詳細画面のお気に入りボタン
- NavigationBarに配置（UIBarButtonItem）
- アイコン:
  - オン時: heart.fill（プライマリカラー）
  - オフ時: heart（グレー）
- タップ時:
  - Core DataのisFavoriteを切り替え
  - バウンス + 360度回転アニメーション（0.3秒）

#### 一覧画面のスワイプアクション
- UISwipeActionsConfiguration（左スワイプ）
- スワイプアクション背景: プライマリカラー
- アイコン: heart.fill（白色）
- タイトル: "お気に入り" または "解除"

### お気に入り一覧

#### タブ構成
- UITabBarControllerの2つ目のタブ
- タブアイコン: heart.fill
- タブタイトル: "お気に入り"
- タブカラー: プライマリカラー（選択時）

#### 画面構成
- RecordListViewControllerと同様の2列グリッドレイアウト
- isFavorite = trueの記録のみを表示
- NSFetchedResultsControllerでフィルタリング
  - NSPredicate: `isFavorite == true`
- 訪問日の新しい順でソート

#### 空状態
お気に入りが0件の場合:
- アイコン: heart.circle（80×80pt、薄いグレー）
- メッセージ: 「お気に入りがありません」
- サブメッセージ: 「気に入ったラーメンを記録してみましょう！」

### お気に入りバッジ
- RecordCellの右上に表示（写真の上に重なる）
- アイコン: heart.fill（プライマリカラー、24×24pt）
- 背景: 半透明白色の円形
- お気に入りの記録のみ表示

## 7. データ同期

### Core DataとUIの同期
- NSFetchedResultsControllerを使用
- NSFetchedResultsControllerDelegateで変更を検知
- controllerDidChangeContent(_:)でUICollectionViewを更新
  - 簡易実装: `collectionView.reloadData()`
  - 詳細実装: `performBatchUpdates(_:completion:)` で個別セルを更新

### 複数画面間の同期
- 記録一覧、お気に入り一覧、詳細画面は同じCore Dataコンテキストを参照
- 一つの画面でデータを変更すると、NSFetchedResultsControllerを通じて他の画面も自動更新
