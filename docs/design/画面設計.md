# 画面設計書

**作成日:** 2026年2月1日
**更新日:** 2026年2月7日

---

## 1. 画面一覧

| 画面名 | ViewController | 説明 |
|---|---|---|
| ホーム（記録一覧） | RecordListViewController | 全記録を2列グリッドで表示、検索機能付き |
| 新規記録 | AddRecordViewController | 記録作成フォーム |
| 記録詳細 | RecordDetailViewController | 記録の詳細表示、編集・削除・お気に入り操作 |
| お気に入り一覧 | FavoriteListViewController | お気に入り済みの記録のみを2列グリッドで表示 |

---

## 2. ナビゲーション構造

```
UITabBarController (ルート)
├─ UINavigationController (記録一覧タブ)
│  ├─ RecordListViewController
│  ├─ AddRecordViewController (モーダル)
│  └─ RecordDetailViewController (プッシュ)
└─ UINavigationController (お気に入りタブ)
   ├─ FavoriteListViewController
   └─ RecordDetailViewController (プッシュ)
```

### TabBarの構成

**タブ1: 記録一覧**
- アイコン: `fork.knife`
- タイトル: "記録"
- 初期表示画面: RecordListViewController

**タブ2: お気に入り**
- アイコン: `heart.fill`
- タイトル: "お気に入り"
- 初期表示画面: FavoriteListViewController

## 3. 各画面の詳細設計

### 3.1 RecordListViewController（記録一覧）

#### 画面構成
```
┌─────────────────────────────┐
│ ← 記録          🔍 ➕ 🎚️  │ NavigationBar
├─────────────────────────────┤
│ [検索バー]                  │ UISearchController
├─────────────────────────────┤
│                             │
│  ┌────┐  ┌────┐            │
│  │Card│  │Card│            │
│  │ 1  │  │ 2  │            │ UICollectionView
│  └────┘  └────┘            │ (2列グリッド)
│  ┌────┐  ┌────┐            │
│  │Card│  │Card│            │
│  │ 3  │  │ 4  │            │
│  └────┘  └────┘            │
│                             │
├─────────────────────────────┤
│   📝 記録      ❤️ お気に入り │ TabBar
└─────────────────────────────┘
```

#### NavigationBar
- タイトル: "記録"（20pt、Bold）
- 右ボタン1: 検索ボタン（magnifyingglass）→ UISearchControllerをアクティブ化
- 右ボタン2: +ボタン（plus.circle.fill、プライマリカラー）→ AddRecordViewControllerをモーダル表示
- 右ボタン3: フィルターボタン（line.3.horizontal.decrease.circle）→ ラーメン種類フィルター

#### UISearchController
- プレースホルダー: 「店名やラーメンの種類で検索」
- 検索バーのスタイル: prominent
- hidesNavigationBarDuringPresentation: false

#### UICollectionView
- レイアウト: UICollectionViewFlowLayout（2列グリッド）
- セル: RecordCell
- 背景色: 明るいグレー（#F7F7F7）

#### 空状態
- アイコン: bowl.fill（80×80pt）
- メッセージ: 「まだラーメンの記録がありません」
- サブメッセージ: 「＋ボタンから最初の記録を追加しましょう！」

## 4. RecordCell（CollectionViewセル）

### セル構成
```
┌─────────────────┐
│                 │
│  ┌───────────┐  │ ← 写真エリア（高さ120pt）
│  │           │  │    角丸12pt（上部のみ）
│  │   写真    │❤️ │    お気に入りバッジ（右上）
│  │           │  │
│  └───────────┘  │
│                 │
│ 店舗名（2行）   │ ← テキストエリア
│                 │    パディング8pt
│ [醤油ラーメン]  │ ← タグ
│                 │
│ 2026/02/01      │ ← 日付
│                 │
└─────────────────┘
```

### セルサイズ
- 幅: `(画面幅 - 左右マージン32pt - 列間隔12pt) / 2`
- 高さ: 幅 × 1.3（アスペクト比）

### 表示要素
1. **写真**（上部、高さ120pt）
   - 角丸12pt（上部のみ）
   - 写真がない場合: グレー背景 + fork.knifeアイコン

2. **お気に入りバッジ**（写真の右上に重なる）
   - heart.fill（プライマリカラー、24×24pt）
   - 半透明白背景の円形
   - お気に入りのみ表示

3. **店名**（写真の下）
   - 15pt、Semibold、ダークグレー
   - 2行まで表示、省略記号

4. **ラーメンの種類**（タグ形式）
   - イエロー背景、角丸8pt
   - 12pt、Medium

5. **訪問日**（下部）
   - 12pt、Regular、グレー
   - フォーマット: "yyyy/MM/dd"

### スタイル
- 背景: 白色
- 角丸: 12pt
- シャドウ: shadowOpacity = 0.1、shadowRadius = 8、shadowOffset = (0, 2)
- 内部パディング: 8pt

## 7. モーダル遷移

### AddRecordViewController
- プレゼンテーションスタイル: pageSheet（iOS 13+）
- 下スワイプで閉じる: 無効（isModalInPresentation = true）
- 保存またはキャンセルボタンで明示的に閉じる

## 8. アクセシビリティ

### VoiceOver対応
- 全てのインタラクティブ要素にaccessibilityLabelを設定
- セル: "店名、ラーメンの種類、訪問日、お気に入り（状態）"
- ボタン: "新規記録を追加"、"お気に入りに追加"など

### Dynamic Type対応
- システムフォントサイズの変更に対応
- UIFontMetricsを使用したスケーリング

### カラーコントラスト
- テキストとBackgroundのコントラスト比: 最低4.5:1
