# 画面設計書

**作成日:** 2026年2月1日
**更新日:** 2026年2月17日

---

## 1. 画面一覧

| 画面名 | ViewController | 説明 |
|---|---|---|
| ホーム（記録一覧） | RecordListViewController | 全記録を2列グリッドで表示、検索・フィルター機能付き |
| 新規記録 | AddRecordViewController | 記録作成・編集フォーム |
| 記録詳細 | RecordDetailViewController | 記録の詳細表示、編集・削除・お気に入り操作 |
| お気に入り一覧 | FavoriteListViewController | お気に入り済みの記録のみを2列グリッドで表示 |

### 共通基底クラス
- **BaseRecordListViewController**: RecordListViewControllerとFavoriteListViewControllerの共通基底クラス
  - 2列グリッドCollectionView、空状態表示、スタガーアニメーション、NSFetchedResultsControllerデリゲートを共通化
  - サブクラスはfetchPredicate()、emptyState系プロパティ、setupAdditionalUI()等をオーバーライド

## 2. ナビゲーション構造

```
UITabBarController (ルート)
├─ UINavigationController (記録一覧タブ)
│  ├─ RecordListViewController
│  ├─ AddRecordViewController (モーダル fullScreen)
│  └─ RecordDetailViewController (プッシュ)
│     └─ AddRecordViewController (モーダル fullScreen、編集)
└─ UINavigationController (お気に入りタブ)
   ├─ FavoriteListViewController
   └─ RecordDetailViewController (プッシュ)
      └─ AddRecordViewController (モーダル fullScreen、編集)
```

### TabBarの構成

**タブ1: 記録一覧**
- アイコン: `fork.knife`
- タイトル: "記録"
- 初期表示画面: RecordListViewController

**タブ2: お気に入り**
- アイコン: `heart.fill`
- タイトル: "お気に入り"

## 4. RecordCell（CollectionViewセル）

### セル構成
```
┌──────────────────────┐
│                    ❤️ │ ← お気に入りバッジ（右上8pt）
│   上部エリア          │ ← セル高さの60%
│   (写真 or カラー)    │    角丸16pt
│   🍴 (placeholder)   │
│                      │
├──────────────────────┤
│                      │ ← 下部エリア（白背景）
│ 店舗名（2行）        │    10ptパディング
│                      │
│ [醤油] ⭐⭐⭐⭐⭐     │ ← タグ + ミニ星
│                      │
└──────────────────────┘
```

### セルサイズ
- 幅: `(画面幅 - 左右マージン20pt - 列間隔12pt) / 2`
- 高さ: 幅 x 1.0（正方形）

### 表示要素
1. **上部エリア**（セル高さの60%）
   - 写真がある場合: 写真表示 + ダークグラデーション
   - 写真がない場合: ラーメン種類カラー背景 + fork.knifeアイコン

2. **お気に入りバッジ**（右上8ptマージン）
   - appPrimary背景の円形（24x24pt、cornerRadius 12pt）
   - 白heart.fillアイコン（10pt bold）
   - お気に入りのみ表示

3. **店名**（上部エリアの下10pt）
   - appStoreName（17pt bold）、appText色
   - 2行まで表示、省略記号

4. **ラーメンの種類**（タグ形式）
   - ラーメン種類カラー背景、白テキスト、角丸8pt
   - appTag（12pt bold）
   - パディング: 上下3pt、左右7pt

5. **ミニ星評価**（タグの横、5pt間隔）
   - 5個のミニ星（10x10pt）
   - appSuccess色（選択時）、ライトグレー（未選択時）
   - rating=0の場合は非表示

### スタイル
- 角丸: 16pt
- ハードシャドウ: appBorder色、opacity 1.0、radius 0、offset (0, 5)
- ボーダー: 2pt、appCardBorder色
- タップ時: 5px下にずれてシャドウが消える（3D押し込み効果、0.08秒）

## 8. アクセシビリティ

### VoiceOver対応
- RecordCell: "店名、ラーメンの種類"（accessibilityLabel）、"ダブルタップして詳細を表示"（accessibilityHint）
- FAB: "新しい記録を追加"（accessibilityLabel）
- お気に入りボタン: "お気に入り登録" / "お気に入り解除"（状態により変化）
- 削除ボタン: "記録を削除"（accessibilityLabel）
- 星評価ボタン: "X星"（accessibilityLabel）、選択状態で.selectedトレイト
- 情報行: "タイトル、値"（accessibilityLabel）
- フォーム要素: 各入力フィールドにaccessibilityLabel設定

### Dynamic Type対応
- UIFontMetricsを使用したスケーリング
- 全フォントが rounded(ofSize:weight:) + UIFontMetrics 経由

### カラーコントラスト
- テキストと背景のコントラスト比: 最低4.5:1
