# 006. 記録詳細画面

## 概要
記録の詳細情報を表示する画面を実装する。

## 実装内容

### 1. RecordDetailViewControllerの作成
- UIScrollView内に詳細情報を配置
- 背景色: 明るいグレー（#F7F7F7）

### 2. 詳細情報の表示
- **写真**: 上部、200×200pt、角丸12pt
  - 写真がない場合はプレースホルダー
- **店名**: 24pt、Bold、ダークグレー
- **ラーメンの種類**: タグ形式、イエロー背景、中央寄せ
- **訪問日**: カレンダーアイコン + 日付テキスト
- **費用**: 円マーク + 金額（未入力時は「-」）
- **評価**: 星表示（読み取り専用、32×32pt）
- **コメント**: 白色カード内、角丸12pt（未入力時は非表示）

### 3. NavigationBarの設定
- タイトル: 店名
- 右ボタン1: お気に入りボタン（heart.fill/heart）
- 右ボタン2: 編集ボタン（pencil.circle.fill）

### 4. RecordListViewControllerからの遷移
- セルタップで詳細画面へプッシュ遷移
